# 股票信号卡图生成

## 用途
把 `stock-timing` 的分析结论生成三张竖排卡图，再合并成一张长图。默认不出图；只有用户明确要图时才用本 skill。

## 三张卡内容（固定格式）
- 卡1「买入信号评分」（绿 #0E9F6E）：四维度分条打分 + 总分/10 + 「近期新闻·政策·行业」时间线（带日期 + 利好/利空）。
- 卡2「卖出信号评分 + 谁在玩」（红 #E5484D）：四维度分条打分 + 总分/10 + 「谁在买、谁在卖」清单。
- 卡3「总结」（蓝 #2563EB）：结论、买入分 vs 卖出分、关键价位（支撑/压力/止损）、接下来盯的信号。
- 三张竖排合并成一张长图，底部加「数据来源」栏（逐条列来源 + 免责声明）。

## 图面规范（保持一致）
- 单卡 1080×1700，三张竖排合并；配色：买入绿 #0E9F6E、卖出红 #E5484D、总结蓝 #2563EB，背景 #F7F8FA。
- 字体：标题 STHeiti Medium，正文 Hiragino Sans GB（都在 /System/Library/Fonts/ 下）。
- 全文大白话；「52周」写成「最近一年：最低 X / 最高 Y」。
- 数据来源文字必须自动换行，不允许被截断。
- 维度标签用大白话：公司赚钱变好了吗 / 这个价格贵不贵 / 股价是不是在涨 / 大资金在买吗；卖出侧对应：公司赚钱变差了吗 / 价格是不是太贵 / 股价跌破位了吗 / 有大股东在卖吗。

## 生成方式
用 `scripts/make_cards.py`，改脚本顶部 `DATA` 后运行：
```bash
python3 -m venv /tmp/smoore_venv   # 已存在可跳过
/tmp/smoore_venv/bin/pip install -q pillow
/tmp/smoore_venv/bin/python scripts/make_cards.py
```
输出：`card1_buy.png`、`card2_sell.png`、`card3_summary.png`、`signal_cards.png`（合并长图）。
