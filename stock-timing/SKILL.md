# 股票买卖时机分析框架

## 目标与原则
- 只回答三件事：这票值不值得买？该不该卖？现在该怎么办？
- 价格短期由「情绪 + 筹码 + 资金」决定，长期由「盈利 + 估值」决定。新闻只是噪音，不是买卖理由。
- 跟着「聪明的钱」走往往比看新闻更有把握：先看股东占比、股东类型、钱从哪来、谁在买谁在卖。
- 全文必须用大白话，禁止拽专业词；遇到术语必须写成「术语（就是……）」。
- 数据必须真实、完整、可溯源，并标注日期；拿不到就写「缺失」，严禁编造。

## 第一步：取数（务必完整，按市场分）
行情 / 估值 / 财务（必拿）：
- 现价、市值、市盈率(TTM)、预期市盈率、市净率、股息率、最近一年最高/最低价。
- 最近 3 年的：营业收入、净利润、毛利率（毛利润 ÷ 收入，自己算）。
- 近 120 天走势、20 日均线、60 日均线、近 5/20/60 天涨跌幅。
- 分析师：目标价、评级、有多少家。

资金 / 筹码（谁在玩，必拿，必须真爬数据）：
- 大股东、创始人、高管：增持还是减持（看公司公告、港交所/沪深披露）。
- 南向资金（港股通）/ 北向资金（沪深股通）的持股比例、最近一周净买入/净卖出。
- 机构持仓：前几大基金、持股比例变化。
- A股另看：龙虎榜、大宗交易。

数据来源（按市场）：
- 港股/美股：`yfinance` / `yahoo-finance`；A股：`tushare-finance` / `a-stock-data` / `akshare-stock`。
- 公告/减持：港交所披露易、沪深交易所、公司公告、东方财富。

## 第二步：买入信号评分（满分 10）
| 维度 | 满分 | 打分要点（大白话） |
|---|---|---|
| 公司赚钱变好了吗 | 3 | 净利润从下降变成上升/加速，收入加速，毛利率不再跌 |
| 这个价格贵不贵 | 2 | 市盈率处历史低位，或比同行便宜，或 PEG 小于 1 |
| 股价是不是在涨 | 3 | 站上 20/60 日线、放量止跌、突破前高 |
| 大资金在买吗 | 2 | 利空出尽、减持落地、资金由流出转流入、大家都悲观 |

## 第三步：卖出信号评分（满分 10）
| 维度 | 满分 | 打分要点（大白话） |
|---|---|---|
| 公司赚钱变差了吗 | 3 | 利润下滑、毛利率持续走低、主业不行了 |
| 价格是不是太贵 | 2 | 市盈率远超历史水平，也远超利润增速 |
| 股价跌破位了吗 | 3 | 跌破 20/60 日线、放量下跌 |
| 有大股东在卖吗 | 2 | 大股东/高管减持、资金持续流出、利好兑现、人人都喊买 |

## 第四步：资本怎么买卖（股东占比 + 股东类型 + 谁在买谁在卖，先看这块）

分析任何一只股票，先把「筹码在谁手里、钱从哪来、谁在买谁在卖」查清楚——跟着这些资本走，往往比看新闻更有把握。

### 为什么「谁持有」这么重要（理论支撑）
1. 看谁在卖（最硬的信号）：大股东、创始人、高管最了解公司，他们减持 = 内部人在跑，比任何新闻都可信。例：思摩尔大股东亿纬锂能持股 30.25%，一公告减持，6 月股价跌 32%；小米副董事长林斌一公告减持，市场就慌。
2. 看谁在买（谁在托底）：大股东增持、公司回购、南向/北向加仓 = 有人真金白银接。例：雷军增持小米、南向连续增持思摩尔。
3. 看流通盘大小 / 集中度（决定波动多大）：筹码越集中（大股东+机构占大头，真正自由流通的少），一点点钱就能拉起来或砸下去。例：思摩尔内部人+大股东约 70%，流通盘小，消息一来单日 -19%、一个月 -32%。
4. 看未来供给压力：即将解禁、已公告的减持计划 = 还没砸下来的卖盘。

### 股东占比 + 股东类型（必查，列清楚每一类占多少）
- 创始人 / 实控人：占多少？最近增持还是减持？
- 高管 / 管理层：占多少？
- 机构（基金 / 保险 / 主权基金 / 私募）：占多少？前几大是谁？
- 南向（港股通）/ 北向（沪深股通）：占多少？最近一周净买卖？
- 散户 / 游资：大致 = 总股本减去上面几类。

### 资金买卖的来源（钱从哪来、谁在动，必须真爬数据）
- 大股东 / 高管增减持：公司公告、港交所披露易、沪深交易所。
- 机构持仓变动：institutional_holders / major_holders、基金季报。
- 南向 / 北向净买卖：港股通 / 沪深股通每日数据。
- 公司回购（自己买）、配股 / 增发（新增供给）。
- A股另看：大宗交易、龙虎榜、融资融券。

### 跟着谁买（信号强弱排序，判断依据）
1. 最值得跟（强）：创始人/大股东真金白银增持、公司回购、知名长线机构/主权基金加仓。
2. 较值得跟（较强）：南向/北向持续加仓、高管集体增持。
3. 中性：持股基本不变、散户进出。
4. 要警惕（强卖信号）：大股东/高管减持、机构集中减持、南向/北向持续流出、解禁/增发。

### 落地清单（看一只票的股东 / 筹码，看这 5 项）
1. 大股东、创始人、高管：增持还是减持？
2. 机构：前几大基金在加还是减？
3. 南向 / 北向：持股比例 + 最近一周净买卖？
4. 总股本多大、真正自由流通多少、集中度高不高？
5. 有没有即将解禁或已公告的减持计划？

必写输出：谁在买（大股东增持 / 南向北向加仓 / 机构加仓 / 回购）、谁在卖（大股东减持 / 机构减持 / 南向北向流出），一句话资金面判断（偏多 / 中性 / 偏空）。说不清就写「资金面不明」。

## 第五步：输出格式（纯文字，不出图；用户要图时用 `stock-timing-cards` skill）
按下面三块写：
1. 买入评分：四个维度分条打分 + 总分/10 + 一句话。
2. 卖出评分 + 谁在玩：四个维度分条打分 + 总分/10 + 资金流向结论。
3. 总结：结论、支撑位/压力位/止损、接下来盯的 2–4 个信号、数据来源与日期、免责声明。

结论用词（大白话）：
- 买入 = 明显值得买；观察·分批 = 可以小仓位慢慢买；持有 = 有仓继续拿、不加不追；减仓 = 卖一部分；卖出 = 清仓。

## 时间点复盘（用户问「某天 / 某段时间为什么涨跌」时）

当用户问具体时间点（比如「为什么 X 月 X 日跌了那么多」），不要只讲新闻原因，必须全面复盘，专门回答「谁在卖、谁在买」：

1. 那天/那段发生了什么：事件、公告、宏观、板块联动。
2. 谁在卖：大股东/高管减持？机构减仓？南向/北向净卖出？游资/散户恐慌抛售？
3. 谁在买：大股东/高管增持？回购？南向/北向加仓？机构抄底？
4. 区分「数据」和「推断」：有公告/数据就写数据；没有就明说「这是推断」。
5. 一句话结论：这波是「谁在卖」主导（筹码/基本面），还是「情绪/消息」主导。

## 硬规则
- 不因为「好消息 / 利好兑现」去追高买入。
- 大股东/高管减持是强信号，比一般新闻更优先。
- 估值决定容错率：贵 = 容错低，宁可错过也别买贵。
- 趋势没确认前不逆势重仓（不接飞刀）。
- 结论必须带止损、仓位建议和免责声明。
- 数据必须标来源和日期；专业词必须翻译成大白话。
- 用户问「某天/某段时间为什么涨跌」时，必须回答「谁在卖、谁在买」，并区分数据与推断，不能只讲新闻原因。

## 术语 → 大白话对照（写结论必须用右列）
- 基本面拐点 → 公司赚钱开始变好
- 估值安全边际 → 这个价格便宜、有安全垫
- 趋势右侧 → 股价已经转强、在涨
- 趋势破位 → 股价跌破了关键位置
- 筹码 → 谁手里拿着股票
- 放量 → 成交量明显放大
- 52周 → 最近一年
- 营收 / 净利 → 收入 / 利润

## 理论锚点
- 格雷厄姆 / 巴菲特：安全边际，价格 vs 价值。
- 利弗莫尔：趋势确认、关键点突破、不逆势。
- 欧奈尔（CANSLIM）：利润加速 + 放量突破 + 严格止损。
- 霍华德·马克斯：周期位置、钟摆、第二层思维。
- 塔勒布：尾部风险、仓位管理。
