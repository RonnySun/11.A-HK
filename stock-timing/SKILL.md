# 股票买卖时机分析框架

## 核心思想

价格短期由「情绪 + 筹码」驱动，长期由「盈利 + 估值」决定。新闻只是噪声和催化剂，本身不是买卖理由。判断任何股票的买卖时机，必须把下面四个维度都过一遍，再下结论。

## 第一步：取数（按市场选可用来源）

- 港股/美股：`yfinance` / `yahoo-finance`；A股：`tushare-finance` / `a-stock-data` / `akshare-stock`。
- 必须拿到：现价、市值、PE(TTM)/Forward PE、PB、股息率、52周高低、近3年营收/净利/毛利率、近120日走势、大股东/高管减持公告、分析师目标价与评级。
- 数据必须真实可溯源，标注来源与日期；拿不到就明说「缺失」，严禁编造。

## 第二步：买入四维打分

每项满足记 1 分，累计 ≥2 分才谈得上买点。

1. 基本面拐点：净利从下滑转正或加速、营收加速、毛利率企稳回升。
2. 估值安全边际：PE/PB 处于自身历史低位，或 PEG<1，或明显低于同业。
3. 趋势右侧：站上 20/60 日均线、放量止跌、不再创新低、突破关键位。
4. 情绪/筹码冰点：利空出尽、大股东减持落地、市场悲观、目标价被下修到接近现价。

## 第三步：卖出信号

触发 1–2 条就减仓/清仓。

1. 基本面逻辑破坏：盈利下滑、毛利率持续走低、主业失速。
2. 估值透支：PE 远超历史中枢与增速。
3. 趋势破位：跌破关键支撑/均线、放量下跌。
4. 筹码恶化：大股东/高管减持、大额解禁。
5. 情绪过热：利好兑现、人人喊买、目标价一致看多。

## 第四步：固定输出格式

每只股票输出一张「信号卡」：

- 四维评分表：每项 ✓/✗ + 依据 + 数据。
- 结论：买入 / 观察(分批) / 持有 / 减仓 / 卖出。
- 关键价位：支撑位、压力位、止损参考。
- 下一步盯的 1–3 个信号（如中报、减持公告、站上某均线）。
- 数据来源与时间。
- 固定免责声明：仅供个人研究，不构成投资建议。

## 硬规则（必须遵守）

- 不因「利好新闻 / 利好兑现」追高买入。
- 大股东/高管减持是强信号，优先于一般新闻。
- 估值决定容错率：高估值 = 低容错，宁可错过，不买贵。
- 趋势确认前不逆势重仓（不接飞刀）。
- 结论必须带仓位/止损建议与免责声明。

## 理论锚点

- 格雷厄姆/巴菲特：安全边际，价格 vs 价值。
- 利弗莫尔：趋势确认、关键点突破、不逆势。
- 欧奈尔（CANSLIM）：盈利加速 + 放量突破 + 严格止损。
- 霍华德·马克斯：周期位置、钟摆、第二层思维。
- 塔勒布：尾部风险、仓位管理。
