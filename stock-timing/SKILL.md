# 股票买卖时机分析框架

## 核心思想

价格短期由「情绪 + 筹码 + 资金」驱动，长期由「盈利 + 估值」决定。新闻只是噪声。判断买卖时机 = 分别算「买入评分」和「卖出评分」，并必须搞清楚「谁在买、谁在卖」。

## 第一步：取数（含资金/筹码，必须实际爬取，不许猜）

- 行情/财务：港股/美股用 `yfinance` / `yahoo-finance`；A股用 `tushare-finance` / `a-stock-data` / `akshare-stock`。
- 必拿：现价、市值、PE(TTM)/Forward PE、PB、股息率、52周高低、近3年营收/净利/毛利率、近120日走势、MA20/MA60。
- 资金/筹码（谁在玩）：大股东/高管增减持（公告、大宗交易）、北向/南向资金持股变化、机构持仓（institutional_holders / major_holders）、主力资金净流入流出、成交额异动、龙虎榜。
- 数据必须可溯源 + 标注日期；拿不到写「缺失」，严禁编造；资金流向说不清楚就不下结论。

## 第二步：买入信号评分（满分10）

| 维度 | 分值 | 打分要点 |
|---|---|---|
| 基本面拐点 | 0–3 | 净利转正/加速、营收加速、毛利率企稳回升 |
| 估值安全边际 | 0–2 | PE/PB 历史低位、PEG<1、低于同业 |
| 趋势右侧 | 0–3 | 站上 MA20/60、放量止跌、突破关键位 |
| 资金/情绪冰点 | 0–2 | 利空出尽、减持落地、资金由流出转流入、情绪悲观 |

## 第三步：卖出信号评分（满分10）

| 维度 | 分值 | 打分要点 |
|---|---|---|
| 基本面破坏 | 0–3 | 盈利下滑、毛利率持续走低、主业失速 |
| 估值透支 | 0–2 | PE 远超历史中枢与增速 |
| 趋势破位 | 0–3 | 跌破 MA20/60、放量下跌 |
| 筹码恶化/情绪过热 | 0–2 | 大股东/高管减持、资金持续流出、利好兑现、一致看多 |

## 第四步：谁在玩（资金/筹码真相，必写）

- 明确列出：谁在卖（大股东/高管/大宗）、谁在买（机构/南向/主力/回购），净流向是流入还是流出。
- 一句话判断资金面多空。

## 第五步：输出三张卡 + 一张合并长图（图片）

- 卡1「买入信号评分」（绿）：
  - 四维度分条打分 + 总分/10。
  - 维度用大白话：公司赚钱变好了吗 / 这个价格贵不贵 / 股价是不是在涨 / 大资金在买吗。
  - 下方加「近期新闻 · 政策 · 行业」时间线（带日期 + 利好/利空）。
- 卡2「卖出信号评分 + 谁在玩」（红）：
  - 四维度分条打分 + 总分/10。
  - 大白话：公司赚钱变差了吗 / 价格是不是太贵 / 股价跌破位了吗 / 有大股东在卖吗。
  - 加「谁在买、谁在卖」：谁在卖(压力)、谁在买(承接)、国际机构、大股东/管理层。
- 卡3「总结」（蓝）：
  - 综合结论（买入/观察/持有/减仓/卖出）、买入分 vs 卖出分。
  - 关键价位（支撑/压力/止损）、下一步盯的信号。
- 三张卡竖排合并成一张长图，底部加「数据来源」栏（逐条列来源 + 免责声明）。

## 第六步：卡片图规范（保持格式一致）

- 单卡 1080×1700；三张竖排合并；配色：买入绿 #0E9F6E、卖出红 #E5484D、总结蓝 #2563EB。
- 字体：中文黑体 + 苹方（STHeiti Medium / Hiragino Sans GB）。
- 全文大白话，禁止「趋势右侧、趋势破位、基本面拐点、估值安全边际」等术语。
- 「52周」写成「最近一年：最低 X / 最高 Y」。
- 数据来源文字必须自动换行，不允许被截断。

## 硬规则（必须遵守）

- 不因「利好新闻 / 利好兑现」追高买入。
- 大股东/高管减持是强信号，优先于一般新闻。
- 估值决定容错率：高估值 = 低容错，宁可错过，不买贵。
- 趋势确认前不逆势重仓（不接飞刀）。
- 资金流向必须实际爬数据；结论必带仓位/止损与免责声明。

## 理论锚点

- 格雷厄姆/巴菲特：安全边际，价格 vs 价值。
- 利弗莫尔：趋势确认、关键点突破、不逆势。
- 欧奈尔（CANSLIM）：盈利加速 + 放量突破 + 严格止损。
- 霍华德·马克斯：周期位置、钟摆、第二层思维。
- 塔勒布：尾部风险、仓位管理。
